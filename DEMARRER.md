# Démarrer avec votre agent

Ouvrez ce dossier avec votre agent et dites-lui :

> Lis START-HERE.md et accompagne-moi en français pour construire ou enrichir le brain de mon entreprise. Utilise ce que je peux fournir maintenant. Le démarrage peut être complet ou partiel selon mes réponses. Préserve ce qui existe déjà.

[START-HERE.md](START-HERE.md) est la procédure de référence pour l'agent. Cette page est son entrée en français.

Vous pouvez apporter une présentation complète de l'entreprise, quelques documents, une conversation, un projet ou simplement un besoin. Vous pouvez répondre à toutes les questions, en passer certaines ou reprendre plus tard. Les connecteurs ne sont pas obligatoires.

L'agent identifie avec vous l'emplacement du **brain privé**, séparé de ce dépôt public. Il y crée ou enrichit les notes utiles, distingue ce qui est confirmé de ce qui manque et explique comment retrouver les informations enregistrées.

Quelques demandes possibles :

- « Je veux organiser tout le contexte de mon entreprise. J'ai le temps de faire le setup maintenant. »
- « Commençons uniquement par le projet de lancement. Voici le brief et notre dernier compte rendu. »
- « Voici notre brain existant. Ajoute cette décision et garde son historique. »
- « J'arrive dans l'équipe. Lis les conventions et intègre ce document au bon endroit. »
- « Je veux comprendre les principes pour les adapter à notre architecture. »

Le brain privé garde une référence à la version du kit utilisée : un agent ouvert dans le brain retrouve ainsi les missions et la méthode, depuis votre copie locale ou depuis le dépôt public. Si vous voulez que vos agents consultent le brain pendant d'autres travaux (projet client, proposition, mail), l'agent peut vous proposer une skill de consultation et une courte consigne pour votre agent ; il ne les installe qu'avec votre accord.

Les missions d'entretien peuvent être lancées à la demande. Si vous souhaitez les planifier, l'agent vous aide à définir les sources, l'autonomie et les limites, puis utilise votre environnement existant. Ce kit ne contient pas de moteur d'exécution ni de scripts d'ingestion à installer.

Pour retrouver les ressources : [README français](README.fr.md), [modèles](templates/README.md), [missions](missions/README.md) et [exemple fictif](examples/studio-brain/README.md).
